## Requirements
BigConfig requires Clojure and Babashka.

<Tabs>

## Creating a BigConfig project
The fastest way to start with BigConfig is to use one of the official templates. The `package` template creates BigConfig Package to create a DigitalOcean droplet running Redis. The `:ssh-key` is optional if you don't have a DigitalOcean account.

``` shell
# Add big-config as tool to Clojure
clojure -Ttools install-latest :lib io.github.amiorin/big-config :as big-config

# Print the help of all templates
clojure -A:deps -Tbig-config help/doc

# Invoke one of the templates with your options
clojure -Tbig-config package :owner <github-owner> :repository <github-repository> :ssh-key <1234>
```
