# <a name="big-config.pluggable">big-config.pluggable</a>


A pluggable workflow allows extending or overriding step behavior using a multimethod.




## <a name="big-config.pluggable/->workflow*">`->workflow*`</a>
``` clojure
(->workflow* {:keys [first-step last-step wire-fn next-fn]})
```
Function.

Similar to `core/->workflow`, but wraps each step execution in the [`handle-step`](#big-config.pluggable/handle-step)
  multimethod, allowing for external extension or overriding of specific steps.
<p><sub><a href="https://github.com/amiorin/big-config/blob/main/src/clj/big_config/pluggable.clj#L15-L33">Source</a></sub></p>

## <a name="big-config.pluggable/handle-step">`handle-step`</a>




A multimethod that dispatches on the `step`. It is used by [`->workflow*`](#big-config.pluggable/->workflow*) to
  allow pluggable step handling.

  The `:default` implementation calls the original function provided by the
  `:wire-fn` in [`->workflow*`](#big-config.pluggable/->workflow*).
