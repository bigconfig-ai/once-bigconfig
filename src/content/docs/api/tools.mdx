# <a name="big-config.tools">big-config.tools</a>



  This is the list of templates available in BigConfig out of the box.

  Available templates:
  * **[`terraform`](#big-config.tools/terraform)**: Scaffold a project to manage Terraform/Tofu with BigConfig.
  * **[`devenv`](#big-config.tools/devenv)**: Generate devenv files for Clojure and Babashka development.
  * **[`dotfiles`](#big-config.tools/dotfiles)**: Manage user configuration (dotfiles) with templates.
  * **[`ansible`](#big-config.tools/ansible)**: Scaffold an Ansible-based infrastructure project.
  * **[`multi`](#big-config.tools/multi)**: A hybrid template for projects using both Ansible and Terraform.
  * **[`action`](#big-config.tools/action)**: Create GitHub Actions workflows for Clojure projects.
  * **[`package`](#big-config.tools/package)**: Scaffold a BigConfig package for deep automation.
  * **[`generic`](#big-config.tools/generic)**: A base template for generic infrastructure projects.
  * **[`tools`](#big-config.tools/tools)**: Create a `tools.clj` for programmatic workflow control.

  See [Clojure Tools](/guides/clojure-tools/) guide.
  




## <a name="big-config.tools/action">`action`</a>
``` clojure
(action & {:as args})
```
Function.

Create a GitHub action for the CI of a Clojure project.

  Options:
  - :target-dir  target directory for the template ([`action`](#big-config.tools/action) is the default)
  - :overwrite   true or :delete (the target directory)

  Example:
    clojure -Tbig-config action

## <a name="big-config.tools/terraform">`terraform`</a>
``` clojure
(terraform & {:as args})
```
Function.

Create a repo to manage Terraform/Tofu projects with BigConfig.

  Options:
  - :target-dir  target directory for the template (`terrafom` is the default)
  - :overwrite   true or :delete (the target directory)
  - :aws-profile aws profile in ~/.aws/crendentials
  - :region      aws region
  - :dev         aws account id for dev
  - :prod        aws account id for prod

  Example:
    clojure -Tbig-config terraform :region us-west-1

## <a name="big-config.tools/tools">`tools`</a>
``` clojure
(tools & {:as args})
```
Function.

Create a tools.clj for a Clojure project.

  Options:
  - :target-dir  target directory for the template (current directory is the default)
  - :path        path for the clojure source code
  - :ns          namespace containing the file tools.clj
  - :name        override the default name [`tools`](#big-config.tools/tools)

  Example:
    clojure -Tbig-config tools
