The dotfiles template allows to implement layers and conditional logic in your dotfiles. With layers you can have a dotfile in Macos but not in Ubuntu. With conditional logic you can have optional blocks. Secrets are managed like in other projects with environment variables. The template function `lookup-env` is resolving environment variables.

<Tabs>
  <TabItem label="common">
```toml
[user]
    email = 32617+amiorin@users.noreply.github.com
    name = Alberto Miorin
[pull]
    ff = only
    rebase = true
[init]
    defaultBranch = main
{%- if profile = "macos" %}
[url "https://{{ "GITHUB_TOKEN" | lookup-env }}:x-oauth-basic@github.com/"]
    insteadOf = https://github.com/
{%- endif %}
```
  </TabItem>

## Requirements
BigConfig requires Clojure and Babashka. You should also configure
<ExternalLink href="https://direnv.net/">dirvenv</ExternalLink> for your shell.

<Tabs>
  <TabItem label="brew">
``` shell
brew install clojure/tools/clojure
brew install borkdude/brew/babashka
brew install direnv
```
  </TabItem>
  <TabItem label="devbox">
``` shell
devbox global add clojure
devbox global add babashka
devbox global add direnv
```
  </TabItem>
</Tabs>

## Getting started
If you are still learning Clojure, you can still use BigConfig to manage your dotfiles without coding.

<Steps>
1. Create the dotfiles project
   ``` shell
   # Add big-config as tool to Clojure
   clojure -Ttools install-latest :lib io.github.amiorin/big-config :as big-config

   # Invoke the dotfiles template
   clojure -Tbig-config dotfiles
   ```
1. Copy the first
   ``` shell
   cp ~/.gitconfig resources/stage-1/common/dotfiles/.gitconfig
   ```
1. Configure git
   ``` shell
   git init
   git add
   git commit
   git push
   ```
</Steps>

## Common operations

``` shell
# Show dotfiles tasks
bb tasks
# Show dotfiles help
bb help
# Diff your dotfiles
bb diff
# Install your dotfiles
bb install
```

Getting started with BigConfig for dotfiles doesn't require knowing Clojure for the basic operations. You can read more about this use case in this blog article <ExternalLink href="/blog/a-new-approach-to-dotfiles-management-with-bigconfig/">blog article</ExternalLink>.
