## Requirements
BigConfig requires Clojure and Babashka. You should also configure
<ExternalLink href="https://direnv.net/">dirvenv</ExternalLink> for your shell.

<Tabs>
  <TabItem label="brew">
``` shell
brew install clojure/tools/clojure
brew install borkdude/brew/babashka
brew install direnv
```
  </TabItem>
  <TabItem label="devbox">
``` shell
devbox global add clojure
devbox global add babashka
devbox global add direnv
```
  </TabItem>
</Tabs>

## Getting started

<Steps>
1. Create the ansible project
   ``` shell
   # Add big-config as tool to Clojure
   clojure -Ttools install-latest :lib io.github.amiorin/big-config :as big-config

   # Invoke the ansible template
   clojure -Tbig-config ansible
   ```
1. Configure git
   ``` shell
   git init
   git add
   git commit
   git push
   ```
1. Shows the Babashka tasks
   ``` shell
   bb tasks
   ```
1. Show the BigConfig DSL manual.
   ``` shell
   bb show-help
   ```
</Steps>

## Conclusion
Ansible files are either YML or JSON. Many of them should be generated with code like the inventory and the variable files. Have a look at this BigConfig Ansible <ExternalLink href="https://github.com/amiorin/dotfiles-v3/tree/ansible"> project</ExternalLink>.
