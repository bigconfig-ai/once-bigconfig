## Exceptional Developer Experience
Deploying complex software should feel like a built-in command. BigConfig transforms manual provisioning into a clean, repeatable CLI experience.

### Example: Managing Redis
Deploy Redis to your specific stack:
```shell
bb redis create

```

Tear down the instance when no longer needed:

```shell
bb redis delete

```
