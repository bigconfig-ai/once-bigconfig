<CardGrid>
<Card icon="document" title="Deploy Any Software to Any Stack">
Stop inflating your infrastructure just to accommodate new software requirements. With BigConfig, you package your applications to fit your existing environment, not the other way around.
</Card>
<Card icon="heart" title="No Kubernetes, no problem">
Forget the "Kubernetes tax"—you shouldn't have to manage a complex K8s cluster simply because a vendor distributed their tool via Helm. BigConfig empowers you to build packages tailored to your specific stack, giving you total control over your deployment architecture.
</Card>
<Card icon="setting" title="Master the Brownfield">
You don't need a "greenfield" project or a fresh start to see the value of BigConfig. We meet you exactly where you are. BigConfig allows you to automate legacy, manual provisioning processes without the "rip and replace" headache. It acts as a high-level orchestrator, unifying your existing tools and workflows into a streamlined, automated pipeline.
</Card>
<Card icon="rocket" title="Powered by Clojure">
With Clojure, you already have the ability to handle any automation task. This is a contrast to many modern CLI tools, like Helm, Helmfile, Kustomize, CUE, Dhall, Jsonnet, KCL, and Pkl. BigConfig, implemented in Clojure, provides the essential building blocks — a **workflow** and a **template** engine — that let you use the full power of a dynamic programming language without compromise.
</Card>
</CardGrid>
