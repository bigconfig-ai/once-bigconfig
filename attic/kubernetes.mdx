Currently, BigConfig provides a template and a library to streamline Terraform projects. While similar productivity tools for Kubernetes are in the planning stages, they are not yet available. You should use the generic template and write your own automation code.

## Requirements
BigConfig requires Clojure and Babashka. You should also configure
<ExternalLink href="https://direnv.net/">direnv</ExternalLink> for your shell.

<Tabs>
  <TabItem label="brew">
``` shell
brew install clojure/tools/clojure
brew install borkdude/brew/babashka
brew install direnv
```
  </TabItem>
  <TabItem label="devbox">
``` shell
devbox global add clojure
devbox global add babashka
devbox global add direnv
```
  </TabItem>
</Tabs>

## Getting started

<Steps>
1. Create the generic project
   ``` shell
   # Add big-config as tool to Clojure
   clojure -Ttools install-latest :lib io.github.bigconfig-ai/big-config :as big-config

   # Invoke the generic template
   clojure -Tbig-config generic
   ```
1. Configure git
   ``` shell
   git init
   git add
   git commit
   git push
   ```
1. Shows the Babashka tasks
   ``` shell
   bb tasks
   ```
1. Show the BigConfig DSL manual.
   ``` shell
   bb help
   ```
</Steps>

## Conclusion
BigConfig can replace or improve many tools like Helm, Helmfile, or Kustomize.
