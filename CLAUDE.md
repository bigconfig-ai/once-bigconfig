# CLAUDE.md - AI Assistant Guide

## Project Overview

This is the static website for BigConfig, a Clojure-based infrastructure package manager. It is built with Astro, MDX, Tailwind CSS v4, and local Astro components. Starlight has been removed.

## Tech Stack

| Layer | Tool | Version |
|---|---|---|
| Site generator | Astro | ^6.3.1 |
| MDX | @astrojs/mdx | ^5.0.4 |
| Diagrams | astro-d2 | ^0.8.0 |
| CSS | Tailwind CSS v4 | ^4.1.13 |
| Tailwind integration | @tailwindcss/vite | ^4.1.13 |
| Package manager | pnpm | v10.33.2 |
| TypeScript | strict Astro config | via `astro/tsconfigs/strict` |

## Blog

- Blog posts live in `src/content/docs/blog/`.
- Blog URLs are generated from filenames, for example `my-post.mdx` becomes `/blog/my-post/`.
- The blog preserves index, pagination, post pages, tag pages, author pages, and RSS.
- `src/lib/blog.ts` contains slugging, pagination, author, tag, and RSS helpers.
- `src/layouts/BlogLayout.astro` contains the blog shell and typography styles.
- Cover images live in `public/blog/` and should be referenced as `/blog/image-name.png`.
- Author defaults to `amiorin` when omitted.
- The blog shows 10 posts per page.

Example frontmatter:

```yaml
---
title: "Post Title"
date: 2026-04-01
excerpt: |-
  Multi-line excerpt shown in blog listings.
authors: amiorin
tags:
  - bigconfig
  - clojure
cover:
  alt: Alt text
  image: /blog/blog-image.png
---
```

## Components

Use local Astro components instead of Starlight components:

```mdx
import LinkCard from "~/components/LinkCard.astro";
import Tabs from "~/components/Tabs.astro";
import TabItem from "~/components/TabItem.astro";
import Steps from "~/components/Steps.astro";
import FileTree from "~/components/FileTree.astro";
```

Other common components:

| Component | Usage |
|---|---|
| `YouTube.astro` | Responsive YouTube embed |
| `ExternalLink.astro` | External link with icon and `rel=noopener noreferrer` |

## Removed Docs

Former docs routes under `/api`, `/libraries`, `/templates`, `/start-here`, and `/references` redirect to `/manual`. Keep `src/pages/manual.html` as the replacement manual.

## Styling

- Tailwind CSS v4 is loaded from `src/styles/global.css`.
- Prefer local Astro components and scoped styles over adding global CSS.
- There is no `tailwind.config.*` file.
