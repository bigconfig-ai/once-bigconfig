# Plan 14 — Add environment to homepage launcher example

## Context read

- Read `src/pages/index.astro`.
- The homepage currently has a `#launcher-example` section before `#deploy`.
- `#launcher-example` currently lets users choose two independent inputs:
  1. Launcher: `uvx` or `npx`
  2. Target language: TypeScript, Python, or Clojure
- The generated shell command currently renders with a prompt prefix, for example:

  ```sh
  $ npx bc-pkg bigconfig-ai/once@typescript package validate
  ```

- The Copy button currently copies the command without the `$ ` prefix.
- The homepage still has a `#deploy` section using `Tabs` / `TabItem` with `plan.md`, `bb.edn`, and `Run` examples.
- The top desktop and mobile nav both link to `#deploy`.

## Goal

Update the homepage launcher example so users can choose a third input: Environment.

The three inputs should become:

1. Launcher: `uvx` or `npx`
2. Target language: TypeScript, Python, or Clojure
3. Environment: `Shell` or `Prompt`

Also remove `#deploy` from the homepage.

## Environment behavior

Let `command` be the selected launcher/language command without a shell prompt prefix:

```text
{launcher} bc-pkg bigconfig-ai/once@{language} package validate
```

### Shell mode

Shell mode should keep the current behavior:

```sh
$ {command}
```

Example default:

```sh
$ npx bc-pkg bigconfig-ai/once@typescript package validate
```

### Prompt mode

Prompt mode should render an agent-ready instruction using the same command without `$ `:

```md
- run {command}
- iterate on failure
```

Example default:

```md
- run npx bc-pkg bigconfig-ai/once@typescript package validate
- iterate on failure
```

## Required command mapping

| Launcher | Target language | Command |
|---|---|---|
| `uvx` | TypeScript | `uvx bc-pkg bigconfig-ai/once@typescript package validate` |
| `uvx` | Python | `uvx bc-pkg bigconfig-ai/once@python package validate` |
| `uvx` | Clojure | `uvx bc-pkg bigconfig-ai/once@clojure package validate` |
| `npx` | TypeScript | `npx bc-pkg bigconfig-ai/once@typescript package validate` |
| `npx` | Python | `npx bc-pkg bigconfig-ai/once@python package validate` |
| `npx` | Clojure | `npx bc-pkg bigconfig-ai/once@clojure package validate` |

## Proposed implementation

1. In `src/pages/index.astro`, add a third segmented control inside `#launcher-example`:
   - Label: `Environment`
   - Buttons: `Shell`, `Prompt`
   - Use the existing `.command-option` style and `aria-pressed` pattern.
2. Extend the inline JavaScript state:

   ```js
   const state = { launcher: "npx", language: "typescript", environment: "prompt" };
   ```

3. Split output generation into two functions:

   ```js
   const getCommand = () =>
     `${state.launcher} bc-pkg bigconfig-ai/once@${state.language} package validate`;

   const getDisplayText = () =>
     state.environment === "prompt"
       ? `- run ${getCommand()}\n- iterate on failure`
       : `$ ${getCommand()}`;
   ```

4. Update the generated code block from `getDisplayText()` whenever launcher, language, or environment changes.
5. Update the Copy button to copy the generated text for the selected environment exactly as visible.
   - In Shell mode, copy the visible `$ ...` line.
   - In Prompt mode, copy the visible two-line prompt exactly.
6. Update the small label above the code block from `package validate` to a mode-aware label if desired, for example:
   - `shell command`
   - `agent prompt`
7. Remove the existing `#deploy` section from `src/pages/index.astro`.
8. Clean up anything made unused by removing `#deploy`:
   - Remove `Tabs` and `TabItem` imports if they are no longer used.
   - Remove `planMd`, `bbEdn`, and `runSh` constants if they are no longer used.
   - Remove desktop and mobile nav links to `#deploy`, or retarget them if desired.
   - Remove `.code-tabs` styles if no longer used elsewhere on this page.
9. Run `pnpm build` after editing.

## Decisions

- Remove the entire deploy section and the `#deploy` anchor.
- Remove the `Deploy` nav link from both desktop and mobile nav.
- Default environment: `Prompt`.
- Prompt mode Copy copies exactly the visible two-line prompt.
- Shell mode Copy copies exactly the visible `$ ...` line.
- Change the code-block header label dynamically between `shell command` and `agent prompt`.
