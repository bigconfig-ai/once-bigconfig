# Goal
SVG banner to announce that BigConfig now supports Clojure, TypeScript, and Python.

# Deliverables
- SVG
- PNG files
- Linkedin files

# Ideas
- Coding agents are changing the game. Supporting multiple languages for a tool is not a problem anymore.
- Ask your coding agent to write the package in the language your are most familiar. Review it and test it. The coding agent will maintain the other implementation out of the box.
- The rendered configuration files is the test to verify that every implementation of the package is correct.
- The configuration files are shared between implementation
- Simpler than CDK and Pulumi.
