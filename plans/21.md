# Plan 21 — Redesign the homepage around the Open Agent Packages Ecosystem

## Goal

Rebuild `src/pages/index.astro` so the entire page tells one story:

> **BigConfig is the Open Agent Packages Ecosystem. Packages are reusable
> capabilities for AI agents — like Skills, but executable.**

Everything else on the page should support that single idea. Source of
truth for the messaging is `src/content/docs/blog/skills-vs-bigconfig-packages.mdx`.

## Narrative arc (new section order)

1. **Hero** — "The Open Agent Packages Ecosystem" + "Like Skills, but executable" subtitle. No CTAs.
2. **What is a package?** — short two-column explainer (prose + a code/invocation snippet).
3. **Skills vs Packages** — comparison table pulled from the blog.
4. **Four differentiators** — replacement feature grid (shell-native, software-grade, lifecycle contract, durable artifacts).
5. **Who runs a package** — four-up grid: agent, shell, CI, container — driving home shell-native portability.
6. **The lifecycle contract** — restructured launcher widget that leads with verbs + credential scoping.
7. **See it in action** — keep the YouTube demo, retitled.
8. **Dive deeper** — trimmed link grid: Marketplace, Manual, Blog. (Drop "Support".)
9. **Footer** — unchanged.

Header/nav and the global styles (`bc-site-card`, `bc-page-light`, `bc-page-glow`,
`bc-nav-link`, gradients, color palette) stay as-is. Tailwind v4 + the existing
`bc-` classes only; no new global CSS unless strictly necessary.

## Messaging guardrails

- Define "Skill" implicitly on first mention; never assume reader knows the term.
- Drop the line "You don't need to learn BigConfig, your agent can operate it for you." entirely.
- Drop the hero CTA buttons (Marketplace + GitHub) entirely.
- Do **not** link to the blog post `skills-vs-bigconfig-packages` from the hero.
  It is fine to link from later sections (e.g., comparison table caption).
- Anchor lifecycle verbs as **validate / build / create / describe / delete**,
  with credential scoping (safe / neutral / danger) already encoded in the
  launcher.
