## Goal

Update the homepage launcher example so credential feedback is communicated by color rather than icons.

Credential categories:

- No credentials: `build` with a neutral color
- Read-only credentials: `validate`, `describe` with a safe color
- Read-write credentials: `create`, `delete` with a danger color

Verb order must be:

1. `validate`
2. `build`
3. `create`
4. `describe`
5. `delete`

## Decisions

1. Remove icons completely from both the verb buttons and the credential output pill.
2. Use color as the only credential-category visual cue.
3. Apply category colors to all relevant button/pill surfaces:
   - Border
   - Text
   - Background tint
   - Hover state
   - Focus state
   - Selected state
4. Use dark-mode-compatible colors:
   - Neutral / no credentials: neutral gray
   - Safe / read-only credentials: emerald green
   - Danger / read-write credentials: rose red
5. Selected verb buttons should use the credential category color instead of the current cyan selected style.
6. Hover and focus states should use the credential category color too.
7. Keep credential output labels as:
   - `No credentials`
   - `Read-only credentials`
   - `Read-write credentials`
8. Keep copy behavior unchanged; credential output remains UI-only and is not copied.

## Implementation direction

1. Keep the existing command-generation behavior intact.
2. Keep the current default verb as `validate`.
3. Reorder the verb buttons to:
   1. `validate`
   2. `build`
   3. `create`
   4. `describe`
   5. `delete`
4. Remove SVG icons from all verb buttons.
5. Remove the SVG icon from the credential output pill.
6. Remove `credentialIcons`, `credentialIcon`, and `credentialIcon.innerHTML` handling from the inline script.
7. Add credential category metadata to each verb, for example:

   ```js
   const credentialRequirements = {
     build: { label: "No credentials", kind: "neutral" },
     validate: { label: "Read-only credentials", kind: "safe" },
     describe: { label: "Read-only credentials", kind: "safe" },
     create: { label: "Read-write credentials", kind: "danger" },
     delete: { label: "Read-write credentials", kind: "danger" },
   };
   ```

8. Add `data-credential="neutral|safe|danger"` to each verb button.
9. Add/update `data-credential` on the credential output pill when `state.verb` changes.
10. Add CSS for category-colored credential controls. Suggested colors:

   ```css
   [data-credential="neutral"] {
     --credential-text: #d4d4d4;
     --credential-border: rgba(163, 163, 163, 0.5);
     --credential-bg: rgba(163, 163, 163, 0.1);
     --credential-ring: rgba(163, 163, 163, 0.22);
   }
   [data-credential="safe"] {
     --credential-text: #34d399;
     --credential-border: rgba(52, 211, 153, 0.6);
     --credential-bg: rgba(52, 211, 153, 0.12);
     --credential-ring: rgba(52, 211, 153, 0.22);
   }
   [data-credential="danger"] {
     --credential-text: #fb7185;
     --credential-border: rgba(251, 113, 133, 0.6);
     --credential-bg: rgba(251, 113, 133, 0.12);
     --credential-ring: rgba(251, 113, 133, 0.22);
   }
   ```

11. Scope category coloring so non-credential options like launcher/package/language/environment keep the existing cyan selected style.
