Current `#launcher-example` state in the source:

- The section exists on the homepage.
- It is currently a dark-mode Tailwind-styled homepage section, not a slide.
- It has five interactive choice groups:
  1. Launcher: `uvx` or `npx`
  2. Package: `bigconfig-ai/once` or `bigconfig-ai/walter`
  3. Target language: TypeScript, Python, or Clojure
  4. Verb: `validate`, `build`, `create`, `describe`, or `delete`
  5. Environment: `Shell` or `Prompt`
- Current defaults in the source are:
  - Launcher: `npx`
  - Package: `bigconfig-ai/once`
  - Target language: `typescript`
  - Verb: `validate`
  - Environment: `prompt`
- The rendered default prompt is currently:

  ```md
  - run npx bc-pkg bigconfig-ai/once@typescript package validate
  - iterate on failure
  ```

- Current verb order is:
  1. `validate`
  2. `build`
  3. `create`
  4. `describe`
  5. `delete`
- Current credential feedback is color-based, not icon-based:
  - `build`: `No credentials`, neutral gray
  - `validate`, `describe`: `Read-only credentials`, emerald/safe green
  - `create`, `delete`: `Read-write credentials`, rose/danger red
- The command card header includes a UI-only credential output pill.
- Current command generation is:

  ```js
  `${state.launcher} bc-pkg ${state.packageName}@${state.language} package ${state.verb}`
  ```

- Current display behavior:
  - Prompt mode displays the two-line prompt block.
  - Shell mode displays `$ {command}` with a `$ ` prefix.
- Current copy behavior:
  - Prompt mode copies the two-line prompt block.
  - Shell mode copies the raw command without the `$ ` prefix.
  - Credential output is UI-only and is not copied.
