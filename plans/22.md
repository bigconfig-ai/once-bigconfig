## Blog article shape

Title:

> I Deleted the Hand-Written Version of BigConfig

Narrative:

1. Open with the Bun rewrite reference.
2. Introduce the provocative production claim: deleted the hand-written BigConfig version and redeployed with the agent-written one.
3. Explain the original Clojure stack and the broader stack scope.
4. Walk through TypeScript → Python → TypeScript back to Clojure.
5. Explain that the work was not just syntax translation.
6. Show how cross-language pressure forced generic contracts:
   - same workflow shape
   - same lifecycle verbs
   - same parameter flow
   - same rendered artifacts
   - same package behavior
   - same engine/tool-runner boundary
   - same runtime string-key boundary
7. Connect to the BigConfig thesis: packages make procedural knowledge executable.
8. Explain why lifecycle verbs are authority boundaries.
9. Explain why the broader stack had to move together.
10. Production proof point: `bigconfig.ai` is deployed by `once`; the agent-written version deployed without incident.
11. Close with the lesson: agents are useful when they work inside clear contracts, reusable libraries, tests, durable artifacts, and human-controlled destructive actions.
